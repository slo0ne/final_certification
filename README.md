## Описание программы

**Book Tracker** — это графическое приложение (GUI) для ведения списка прочитанных книг. Программа позволяет добавлять книги, фильтровать их по жанру и количеству страниц, а также сохранять данные в JSON-файл.

### Основные функции:

- ✅ Добавление книг (название, автор, жанр, количество страниц)
- ✅ Просмотр всех книг в таблице
- ✅ Фильтрация по жанру
- ✅ Фильтрация по количеству страниц (например, больше 200)
- ✅ Удаление выбранной книги
- ✅ Очистка всего списка (с подтверждением)
- ✅ Сохранение и загрузка данных в JSON
- ✅ Проверка корректности ввода (пустые поля, число страниц)
